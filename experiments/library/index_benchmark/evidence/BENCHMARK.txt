All tests used the unchanged experiment-library host, official CPU backend, one native thread, no persistence, and an explicit zero-law benchmark configuration. Normal admission, technical validation, current authentication and sealed prepared artifacts remained enabled.
Two warmups and nine measured rounds; rotated/alternating order. Baseline: identical business data with empty index tables. Same-state control: direct scan with index populated. Each unique query stops at its first match; nonunique baseline reads group once per business row. Matching nonunique queries return 1/8 of rows. Both indexes use the real library helpers. Update benchmarks change indexed values and maintain the real ordinary-table indexes. Old key information is supplied to both variants, favoring the index by excluding any extra old-value fetch.
Every loaded base row and index target/value was checked. Every update was followed by base/index checks, removal checks and nonunique complete-result checks. Expected results computed independently in Python. No universal performance claim.
