# Provas do contrato anterior com recursos físicos

Preservação literal anterior à revisão autorizada de 2026-10-29. Os caminhos
originais são mantidos sob este prefixo e seus SHA-256 constam do manifesto.
Os módulos exclusivamente de memória/prazos e seus controles negativos foram
retirados dos agregados ativos. `proof/Recursos.bend` contém também um lema
de falha real que foi conservado na versão ativa. README e RESULTADOS são
cópias de proveniência anteriores à revisão, não resultados do novo contrato.

Os imports aqui são os originais: este arquivo histórico não é uma nova suíte
ativa. Para reproduzir a versão integral anterior use o snapshot do projeto
`history/antes-da-retirada-dos-recursos-fisicos.tar.gz` e o contrato preservado
em `history/contrato-v1/`. Logs, resultados específicos e fixtures anteriores
continuam nos seus caminhos literais e não foram regravados.
